# LaunchPageWebsiteDJWeddings

This is a Vite-based React landing page for a DJ and event entertainment website.

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the local development server:
   ```bash
   npm run dev
   ```

## Deploying to GitHub Pages

This project is configured to automatically build and deploy to GitHub Pages via GitHub Actions whenever changes are pushed to the `main` branch.
